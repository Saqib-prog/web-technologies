Lecture 07: CSS Layout — Flexbox & Grid

Summary

This lecture covers CSS layout using Flexbox for one-dimensional layouts and Grid for two-dimensional layouts, when to use each one, and how to keep spacing consistent.

Flexbox

Flexbox is a one-dimensional layout model for distributing space among items in a container.

  • display: flex; — Activates flexbox.
  • flex-direction: row | column | row-reverse | column-reverse.
  • justify-content: center | space-between | space-around | flex-start | flex-end.
  • align-items: center | flex-start | flex-end | stretch.
  • gap: Spacing between flex items.

CSS Grid

Grid is a two-dimensional layout system for rows and columns simultaneously.

  • display: grid; — Activates grid.
  • grid-template-columns: Defines column track sizes.
  • grid-template-rows: Defines row track sizes.
  • gap: Spacing between grid cells.
  • grid-column / grid-row: Item placement.

When to Use Which?

  • Flexbox: One-dimensional layouts (nav bars, card rows, centering).
  • Grid: Two-dimensional layouts (page layouts, complex dashboards).

Consistent Spacing

Use a spacing scale (e.g., 8px, 16px, 24px, 32px) for predictable layouts. Prefer gap in flex/grid layouts for consistent separation.
