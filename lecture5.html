Lecture 05: CSS Fundamentals & Selectors

Summary

This lecture introduces CSS and its syntax, the three ways to apply CSS, the different selectors, pseudo-classes and pseudo-elements, and how the cascade and specificity decide which rule is applied.

What is CSS?

CSS (Cascading Style Sheets) controls the presentation of HTML elements. It separates content from presentation and supports consistent, maintainable design.

HTML = content | CSS = presentation

CSS Syntax

selector {
    property: value;
}

Example: p { color: darkblue; font-size: 20px; }

Three Ways to Apply CSS

  • Inline: Inside style attribute (low reusability).
  • Internal: Inside <style> tag in <head> (single page).
  • External: Separate .css file linked via <link> (high reusability).

CSS Selectors

  • Element: p { }
  • Class: .card { }
  • ID: #header { }
  • Attribute: input[type="text"] { }
  • Grouping: h1, h2, p { }
  • Descendant: div p { }
  • Child: div > p { }
  • Adjacent Sibling: h2 + p { }
  • General Sibling: h2 ~ p { }
  • Universal: * { }

Pseudo-Classes vs. Pseudo-Elements

  • Pseudo-class: State/condition (one colon) — :hover, :focus, :nth-child(2).
  • Pseudo-element: Specific part (two colons) — ::before, ::after, ::first-letter.

Cascade & Specificity

Specificity levels (highest to lowest): Inline style → ID → Class/Attribute/Pseudo-class → Element/Pseudo-element → Universal.

Source order = later rule wins when other factors are equal.
