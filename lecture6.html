Lecture 06: CSS Box Model & Display

Summary

This lecture explains the CSS box model (content, padding, border and margin), box-sizing, margin collapsing, the display property, overflow, borders and shadows.

The CSS Box Model

Every HTML element is treated as a rectangular box with four layers:

  • Content: Actual text, image, or child elements.
  • Padding: Space between content and border.
  • Border: Visible edge around padding/content.
  • Margin: Outside space separating boxes.

Box-Sizing

  • content-box (default): width = content only; padding + border added.
  • border-box: width = content + padding + border; outer size stays fixed.

Common pattern: * { box-sizing: border-box; }

Margin Collapsing

When certain vertical margins meet, they combine into a single margin. The larger margin wins.

Example: margin-bottom: 30px + margin-top: 20px → collapsed to 30px.

Display Property

  • block: Starts on a new line, fills available width.
  • inline: Flows within text; width/height don't apply.
  • inline-block: Flows inline but accepts box dimensions.
  • none: Element removed from layout.

Overflow

  • visible: Content extends outside the box.
  • hidden: Extra content is clipped.
  • scroll / auto: Scrolling provided when content overflows.

Borders & Shadows

Border syntax: width + style + color. Common styles: solid, dashed, dotted, double.

Box-shadow adds depth without changing dimensions: box-shadow: 0 6px 18px rgba(0,0,0,.15);
