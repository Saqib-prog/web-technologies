Lecture 01: Course Foundation & The Web

Summary

This lecture introduces the scope and learning outcomes of the course, the difference between the Internet and the World Wide Web, key web terms such as URL, HTTP, DNS and hosting, web standards bodies and the main types of web applications.

Course Overview

This lecture introduces the scope of Web Technologies, learning outcomes, and the assessment plan. The course covers modern web technologies used for web development, web platforms, and architectures.

Internet vs. Web

  • Internet: Global network infrastructure that carries data between connected devices and networks.
  • World Wide Web: A system of interlinked resources and applications that runs on top of the Internet.
  • Analogy: Internet = roads & network; Web = services/content travelling on those roads.

Key Web Terminology

  • URL/URI: Addressing system for web resources.
  • HTTP/HTTPS: Communication protocols between clients and servers.
  • DNS: Domain Name System - converts domain names to IP addresses.
  • Hosting: Service that stores and serves web files.

Web Standards

Standards ensure interoperability and consistency across browsers. Key bodies include:

  • W3C — World Wide Web Consortium
  • WHATWG — Web Hypertext Application Technology Working Group
  • ECMA — JavaScript standardization
  • IETF — Internet Engineering Task Force

Web Application Types

  • Static: Prebuilt files delivered to the user.
  • Dynamic: Content generated from data.
  • MPA: Multi-Page Application with multiple page loads.
  • SPA: Single-Page Application with dynamic views.
  • PWA: Progressive Web Application with app-like capabilities.
